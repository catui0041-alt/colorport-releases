# ColorPort

**أداة تنقل ColorOS إلى شجرة روم هاتفك: تفحص، تخطّط، تنفّذ، تتحقق، وتتراجع.**

المشروع **مغلق المصدر**. هذا المستودع مخصص للنسخ الجاهزة والدليل واستقبال الأعطال،
ولا يحتوي على كود المصدر.

## التنزيل والتشغيل

آخر نسخة من صفحة **Releases**. النسخة الحالية: **Linux x86_64** — ملف تنفيذي واحد،
لا يحتاج تثبيت Python.

```bash
chmod +x colorport
./colorport --help
./colorport demo          # دورة كاملة على شجرتين وهميتين، بلا روم وبلا هاتف
```

إن وُجد ملف `SHA256SUMS` مع الإصدار فتحقّق قبل التشغيل:

```bash
sha256sum -c SHA256SUMS
```

> **أنظمة أخرى:** لا تصدر نسخ رسمية لـWindows أو macOS أو Android بعد. الأداة تعمل حيث
> تعمل نسختها المبنية؛ لا تفترض غير ذلك.

## ماذا تفعل؟

| تفعله | لا تفعله |
| --- | --- |
| تفحص أي روم (HyperOS، ColorOS، Nothing، HiOS، OriginOS، AOSP) وتذكر مصدر كل جواب | لا تعد بـ«بورت مثالي بضغطة زر» |
| تخطّط مقارنةً بـColorOS، ولكل بند في سجل تغييرات ColorOS 17 دور: `auto` / `assist` / `manual` | لا تقول «تعمل» قبل اختبارها على جهاز |
| تنسخ الملفات وتسجّل بصمة كل ملف، وتدمج إعلانات HAL داخل manifest جهازك دون استبداله | لا تعدّل داخل بلوب مغلق |
| تضيف قواعد SELinux مولّدة من رفض `avc` الحقيقي فقط | لا تنسخ قواعد جاهزة من روم آخر |
| تتراجع عن كل تعديل، وتقول بالضبط ما لم تستطع إعادته | لا تفلش الهاتف ولا تجمع صورة قابلة للتفليش |

**`found` تعني «القطع موجودة في الشجرة»، لا «الميزة تعمل».** الفرق هو كل شيء.

## الخصوصية

الأداة نفسها لا تفتح أي اتصال شبكي. أنت من ينزّل الروم، وأنت من يملكه، وأنت المسؤول
عن نسخته الاحتياطية قبل أي تعديل.

## علامات تجارية

ColorOS ملك OPPO، وHyperOS/MIUI ملك Xiaomi، وبقية الأسماء ملك أصحابها. هذا المشروع
غير مرتبط رسمياً بأي شركة مصنّعة، ولا يوزّع أي روم أو بلوب أو مفتاح توقيع.
